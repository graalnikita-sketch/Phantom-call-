# Журнал изменений

## 2026-11-10 — Фаза 1, Android (первая сборка)

- Android-проект: Kotlin, Compose, минимальная версия Android 10.
- Ключ устройства P-256 в Android Keystore, StrongBox при наличии.
- Локальное хранилище, зашифрованное AES-256-GCM ключом из Keystore.
- Создание аккаунта и вход по протоколу сервера; только HTTPS.
- Блокировка приложения системным запросом; запрет снимков экрана.
- Экран приватности: сессии, удаление аккаунта, стирание данных.
- Общие тестовые векторы подписываемых строк для сервера и приложения.
- Сборка и тесты в GitHub Actions; обе сборки прошли с первого запуска.
- На физическом телефоне приложение не запускалось.

## 2026-11-10 — Фаза 1, сервер (часть 1)

- Добавлен сервер `phantomd` на стандартной библиотеке Go, без сторонних зависимостей.
- Регистрация аккаунта: устройство доказывает владение ключом P-256 подписью одноразового запроса.
- Вход: подпись одноразового запроса ключом устройства; сервер выдаёт токен сессии и хранит только его SHA-256.
- Выдача публичных ключей по PHANTOM ID, список сессий, выход, удаление аккаунта, сохранение push-токена.
- Ограничение частоты запросов; журнал без IP-адресов и идентификаторов.
- 16 тестов, включая сценарии атак: чужая подпись, подмена ключа, повтор запроса, просроченный запрос, подпись «не для той операции», ключи не того типа.
- Хранилище пока только в памяти процесса.
