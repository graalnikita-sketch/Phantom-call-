# PHANTOM CALL

Приватные голосовые звонки для Android со сквозным шифрованием. Проект в разработке; **внешнего аудита безопасности не было**.

## Состояние на 10.11.2026

| Часть | Статус |
| --- | --- |
| Фаза 0: архитектура и модель угроз | Готово, шесть решений утверждены владельцем (см. `docs/DECISIONS.md`) |
| Фаза 1, сервер: регистрация, вход по ключу устройства, выдача публичных ключей | Собрано и проверено тестами |
| Фаза 1, сервер: хранение в PostgreSQL | Не сделано: данные пока в памяти (см. `docs/KNOWN_RISKS.md`) |
| Фаза 1, Android-приложение: ключ устройства, шифрованное хранилище, блокировка, экран приватности | Собирается в GitHub Actions, модульные тесты проходят. **На телефоне не запускалось** |

## Сервер

Нужен Go 1.24 или новее. Сторонних зависимостей нет.

```
cd server
go test -race ./...
go run ./cmd/phantomd -addr 127.0.0.1:8080
```

Сервер слушает обычный HTTP на локальном адресе; перед ним должен стоять обратный прокси с TLS 1.3.

Протокол описан в `docs/API.md`.

## Android

Сборка идёт в GitHub Actions (`.github/workflows/android.yml`). Готовый APK лежит в артефактах запуска под именем `phantom-call-debug-apk`.

Приложение принимает только адреса сервера с `https://`.
