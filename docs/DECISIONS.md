# Архитектурные решения

Утверждены владельцем 10.11.2026.

| № | Решение | Выбор |
| --- | --- | --- |
| 1 | Защита сигналинга | Подпись сообщений ключом устройства (без libsignal) |
| 2 | Тип ключа устройства | ECDSA P-256 в аппаратном Android Keystore, неизвлекаемый |
| 3 | Устройств на аккаунт | Одно |
| 4 | Восстановление аккаунта | В MVP нет: потеря телефона означает новый PHANTOM ID |
| 5 | Push | Firebase Cloud Messaging с пустым сообщением |
| 6 | WebRTC | Готовая сборка с контрольной суммой для MVP, своя сборка к релизу |

## Решения, принятые при реализации

| Дата | Решение | Причина |
| --- | --- | --- |
| 10.11.2026 | Сервер фазы 1 написан только на стандартной библиотеке Go | В среде разработки закрыт доступ к proxy.golang.org и sum.golang.org. Загрузка библиотек в обход проверки контрольных сумм означала бы отключение проверки безопасности |
| 10.11.2026 | Отзыв устройства в MVP равен удалению аккаунта | Следствие решений 3 и 4: устройство одно, восстановления нет |
| 10.11.2026 | Сервер хранит SHA-256 токена сессии, а не сам токен | Утечка базы не даёт готовых токенов |
| 10.11.2026 | Ошибки входа неразличимы для клиента | Нельзя перебором узнать, существует ли устройство |
