# Известные уязвимости и нерешённые риски

| № | Риск | Статус |
| --- | --- | --- |
| 1 | Данные сервера хранятся в памяти и пропадают при перезапуске | Открыт. Нужен адаптер PostgreSQL; для него требуется сторонний драйвер, который в текущей среде нельзя загрузить с проверкой контрольных сумм |
| 2 | Android-приложение собрано, но ни разу не запускалось на телефоне | Открыт. Работа Keystore, блокировки и экранов не проверена на устройстве |
| 3 | Сервер не завершает TLS сам | По замыслу: TLS 1.3 даёт обратный прокси. Конфигурация прокси ещё не написана |
| 4 | Ограничение частоты запросов живёт в памяти одного процесса | Приемлемо для одного сервера; при нескольких серверах не работает |
| 5 | Любой вошедший пользователь может запросить публичный ключ по известному PHANTOM ID | По замыслу: без этого нельзя позвонить. Перебор ограничен: 60 бит случайности в ID и 60 запросов в минуту |
| 6 | Сервер может выдать клиенту чужой публичный ключ | Не решается сервером. Защита — на клиенте: запоминание ключа, предупреждение о смене, код безопасности (фаза 2) |
| 7 | Формат подписываемых сообщений не проверен внешним криптографом | Открыт до внешнего ревью |
| 8 | Внешнего аудита безопасности не было | Открыт |
| 9 | Блокировка приложения — это экран-заслон: ключ устройства не привязан к разблокировке | По замыслу для MVP: иначе входящий звонок требовал бы разблокировки до ответа. Пересмотреть в фазе 6 |
| 10 | Действия GitHub Actions закреплены по тегу версии, а не по хэшу коммита | Открыт до фазы 6 |
| 11 | Проверка контрольных сумм зависимостей Gradle не включена | Открыт до фазы 6 |
| 12 | Сборка debug подписана отладочным ключом, не годится для распространения | Открыт до фазы 7 |
